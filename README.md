# ChatFlow

A simple real-time chat app. I built this to get hands-on with WebSockets and see how real-time messaging actually works under the hood.

Still a work in progress — the core messaging works but there's more I want to add (rooms, user auth, message history).

## Running it

Open index.html in a browser, or serve it locally:

`ash
npx serve .
`

## Stack

HTML, CSS, JavaScript — kept it simple on purpose to focus on the WebSocket logic.
